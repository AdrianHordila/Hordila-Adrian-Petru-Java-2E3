
Lab1 Tema- Generare Matrice 2D
Aplicatia genereaza o imagine n x n sub forma unei matrici de intregi (0-255).
Poate desena un dreptunghi negru pe fundal alb sau un cerc alb pe fundal negru.
Daca n este mic (<=30), afiseaza imaginea in consola folosind caractere Unicode.
Daca n este mare, afiseaza timpul de executie si gestioneaza memoria heap.
Comenzi rulare terminal:
java Main.java 30 circle
java Main.java 30 rectangle
java -Xmx4G Main.java 35000 circle
